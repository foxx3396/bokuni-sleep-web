아이폰에서 열고 다시 기록하는 방법

이 웹 주소를 Safari 또는 홈 화면 앱에서 열고 기록해 주세요. 이전 HTML에서 만든 JSON 백업도 불러올 수 있어요.

기록은 이 기기의 브라우저 저장 공간에만 보관하며 서버로 전송하지 않아요. 앱을 지우거나 브라우저 데이터를 지우면 기록을 잃을 수 있어요. Safari 개인 정보 보호 모드나 브라우저 데이터 삭제 후에는 기록이 남지 않을 수 있습니다. 기기 간 자동 동기화는 지원하지 않아요.

‘기록이 담긴 HTML 사본 저장’은 현재 기록을 파일 안에 함께 넣어요. 저장한 최신 사본을 열면 기록을 다시 가져올 수 있습니다. 아이폰 다운로드·공유 화면에서 파일 앱에 실제로 저장되었는지 확인해 주세요.

JSON 백업을 불러오면 날짜별로 합쳐집니다. 같은 날짜는 더 최근에 수정한 기록을 유지합니다. 가져오기 전에 현재 기록도 백업해 두세요.
